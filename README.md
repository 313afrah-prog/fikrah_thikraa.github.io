# رفيق دربي | My Companion

نسخة أولى ثابتة، عربية/إنجليزية، متجاوبة مع الهاتف والكمبيوتر، ومهيأة لـ GitHub Pages.

## الملفات
- `index.html` الواجهة
- `style.css` التصميم
- `script.js` اللغة والتفاعل والبحث والوضع الليلي
- `manifest.json` إعداد PWA
- `sw.js` تخزين أساسي للعمل دون اتصال بعد أول زيارة

## النشر
ارفع الملفات إلى مستودع GitHub Pages، ثم Settings → Pages → Deploy from a branch → main → /(root).
