فكرة وذكرى | Fikrah & Thikraa
نسخة النشر الجاهزة لـ GitHub Pages

الملفات:
- index.html = الموقع العام الذي يرسل للعميل
- admin.html = لوحة الإدارة الخاصة بك
- assets/logo.png = الشعار
- .nojekyll = يمنع مشاكل Jekyll مع الملفات الثابتة

مهم:
لا ترسلي رابط file:///... لأي عميل. بعد رفع هذه الملفات إلى GitHub Pages سيكون الرابط HTTPS.

إذا كان المستودع هو:
313afrah-prog/fikrah_thikraa.github.io
فالرابط المتوقع للموقع هو:
https://313afrah-prog.github.io/fikrah_thikraa.github.io/
ولوحة الإدارة:
https://313afrah-prog.github.io/fikrah_thikraa.github.io/admin.html

إعداد GitHub Pages:
Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > Folder: /(root) > Save

يجب أن يكون index.html في جذر المجلد المنشور، وليس داخل مجلد فرعي.
قد يستغرق النشر عدة دقائق.

كلمة مرور الإدارة الافتراضية في النسخة الحالية: 2468

تنبيه: هذه النسخة تستخدم localStorage للإدارة. لذلك الإدارة ليست قاعدة بيانات سحابية، والتعديلات لا تنتقل تلقائياً إلى أجهزة أخرى. لا تضعِي بيانات حساسة داخل المستودع.
